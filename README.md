# Comandos úteis com laravel

Subir o servidor:

- php artisan serve

ou

- php artisan serve --host=0.0.0.0
  

Realizar a migração ou alteração no banco de dados:

- php artisan migrate

arquivo .env para configuração do banco de dados MySQL:

DB_CONNECTION=mysql

DB_HOST=127.0.0.1

DB_PORT=3306

DB_DATABASE=eventosifsp

DB_USERNAME=root

DB_PASSWORD=



# Comandos úteis com PostGreSQL
Verifique se está em execução no gerenciador de tarefas

Caso esteja é só abrir o PgAdmin no menu iniciar

Configuração do arquivo .env para o PostGreSQL

DB_CONNECTION=pgsql

DB_HOST=127.0.0.1

DB_PORT=5432

DB_DATABASE=eventosifsp

DB_USERNAME=postgres
