# Artefatos da pesquisa em arboviroses

Aqui irei colocar os artefatos gerados.

Este diretório organiza os dados, os documentos semânticos e as ontologias utilizados na pesquisa.

- `data_raw/`: dados brutos das fontes originais.
- `data_processed/`: dados tratados e padronizados.
- `data_docs/`: documentos e metadados semânticos derivados dos dados.
- `ontologias/`: ontologias e arquivos de modelagem semântica.

Arquivos volumosos ou sensíveis não devem ser enviados diretamente ao GitHub.
